# How to: To-dos

**Platform:** Both

## What it is
A checklist of plan steps that an agent publishes as it works. Each step has a status: pending, in progress, completed, or cancelled. In ensemble chats, each participant maintains its own checklist ("lane"). To-dos are read-only — they show what the agent is doing.

## Where to find it
A checklist appears inline in the transcript on the tool-activity row where the agent published it. A **Plan** button (checklist icon) in the composer's telemetry row opens a popover with every lane's full checklist.

## How to use it
1. Watch for a checklist card under an agent's tool activity in the transcript — it shows up to 5 items collapsed, with a count of hidden items.
2. Click that activity row to expand it and see the full checklist with each step's status.
3. Click **Plan** in the composer to open a popover with every active lane's complete checklist.
4. In an ensemble chat, lane headers (provider/role name and color dot) separate each participant's plans.
5. The Plan button shows a dot while a step is in progress and a checkmark once all active steps are complete.
