# How to: Update Pill

**Platform:** Electron

## What it is
A one-click update pill that appears above the sidebar masthead when a new version of TaskWraith is available.

## Where to find it
In the **Sidebar**, directly above the masthead (workspace name / + button area) when an update is ready.

<!-- TODO(screenshot): Sidebar update pill above the masthead -->

## How to use it
1. Look for the pill above the masthead.
2. Click it to start the update download and install.

## Tips & related
- The update process is automatic — no manual download required.
- Check [General tab](../settings-and-configuration/general-tab.md) for update-related behavior toggles.
