# How to: Project Reference Library

**Platform:** Electron

## What it is
A per-Project shelf of the files, folders, links, and GitHub items that matter to it. Entries sit there as a catalogue and do nothing on their own — an agent only sees one when you mark it **Use next** for your next message.

## Where to find it
Select **Work** and choose a Project. The **References** pane opens in the right dock, headed **Project library**.

![Selected Project detail showing the metadata-only References controls](../images/sidebar-navigation__project-reference-library.png)

## How to use it
1. Click **+ File**, **+ Folder**, **+ Link**, or **+ GitHub** to add an entry. You can also drag files onto the pane or paste a link into it.
2. Click **Verify** on a file or folder to check it still exists. Links are never fetched.
3. Click **Use next** on the entries you want the next message to see. The banner shows how many are selected, and **Clear** unselects them all.
4. Click **Remove** to delete an entry from the shelf. This never deletes the underlying file.

## Tips & related
- Selecting an entry is not a blanket grant. The usual per-chat permission and approval flow still applies, and TaskWraith rechecks every item when you send.
- Open a chat inside the Project to use **Use next**; without one the pane stays a catalogue.
