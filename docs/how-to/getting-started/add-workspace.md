# How to: Add Workspace

**Platform:** Electron

## What it is
Add a new workspace folder to the sidebar so TaskWraith can run agents against it.

## Where to find it
Select **Code**, then click the **+** button on the **Workspaces** section header, or go to **Settings → Workspaces → Workspaces**.

![Workspaces section header with its Add workspace plus button](../images/getting-started__add-workspace.png)

## How to use it
1. Select **Code**, then click the **+** beside **Workspaces** (or open **Settings → Workspaces → Workspaces**).
2. Select a folder in the system folder picker.
3. The workspace appears under **Workspaces** on the Code surface.

## Tips & related
