# How to: Add Workspace

**Platform:** Electron

## What it is
Adds a project folder to TaskWraith so you can open chats against it and let agents work in it.

## Where to find it
Select **Code**, then click the **+** on the **Workspaces** section header. You can also use **Settings → Workspaces → Workspaces**.

![Workspaces section header with its Add workspace plus button](../images/getting-started__add-workspace.png)

## How to use it
1. Click **Code** in the sidebar.
2. Click the **+** beside **Workspaces**.
3. Choose a folder in the picker that opens.
4. The folder appears under **Workspaces**. Expand it to start a chat in it.

## Tips & related
- Adding a workspace does not give agents permission to change it — that is still set per chat.
- [Sidebar onboarding hint](sidebar-onboarding-hint.md) — appears when no workspaces exist.
- [Workspaces tab](../settings-and-configuration/workspaces-tab.md) for managing loaded workspaces.
