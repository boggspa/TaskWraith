# How to: Welcome Screen

**Platform:** Electron

## What it is
The screen you see on a new, empty chat before you send anything: a greeting, the composer, and — in a workspace chat — optional dashboards for provider usage and agent activity. With Epic FX and **Weather/Sky** on, the backdrop follows your local weather, daylight, and time of day.

## Where to find it
It opens by itself in the centre of the window whenever you select a new, empty chat.

![General welcome draft with greeting, composer, and weather-aware sky](../images/getting-started__welcome-screen.png)

## How to use it
1. Type a task or question in the composer to start the chat.
2. In a workspace chat, click the branch icon on the row under the composer to pick the branch or worktree this chat will use. Choosing it now avoids switching later, mid-task.
3. In a workspace chat, open the dashboard tabs for token and cost summaries and Agent-pool activity.
4. Use the corner FX menu, or **Settings → App → Appearance**, to show or hide the **Weather/Sky** backdrop.

## Tips & related
- The branch picker only appears here while there is no token tally to show. Once the chat has run a turn, the same picker moves to the row above the composer.
- The popover has **Branches** (changes the checkout), **Create branch**, and **Worktrees** for an isolated copy.
- [First Launch Sheet](first-launch-sheet.md) — shown on very first run.
- [Add workspace](add-workspace.md) to populate the sidebar so chats appear.
- [Appearance tab](../settings-and-configuration/appearance-tab.md) — configure Epic FX and Weather/Sky visuals.
