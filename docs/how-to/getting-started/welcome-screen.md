# How to: Welcome Screen

**Platform:** Electron

## What it is
The Welcome Screen is the view you see when no chat is selected. It shows a greeting, starter prompt suggestions, a usage dashboard, and heatmaps of your activity.

## Where to find it
Appears automatically in the **center stage** when no chat is selected (e.g. on first launch or after closing all chats).

<!-- screenshot-pending: Welcome screen with greeting, starter prompts, and usage dashboard -->

## How to use it
1. Pick a starter prompt to begin a new chat.
2. Review the usage dashboard for provider token/cost summaries.
3. Explore the heatmaps to see your activity patterns.
