# How to: Inline transcript media

**Platform:** Both

## What it is
The inline media strip is the row of attachment cards that appears under a chat message whenever that message carries images, audio, video, or file/folder references — uploads you sent, or media an agent generated or attached while responding.

## Where to find it
It renders automatically beneath any transcript message (user or assistant) that has attachments, directly in the chat view — no separate panel to open. Images you already see inline in the message text are not duplicated in the strip; only the remaining attachments show as cards.

## How to use it
1. Click an image card to open it full-size in the preview overlay; click again outside the image, press Escape, or use the close button to dismiss it.
2. Click an audio or video card's name (or its expand button) to open that preview overlay, with playback controls and, for audio, the waveform player.
3. For audio/video cards, use the pop-out button to detach playback into its own Multiview pane instead of playing it inline.
4. Use a card's actions menu (or the overlay's action menu) to open the file in Finder, copy its path, or save a copy, depending on what the attachment supports.
5. For plain file or folder attachments without a preview, click the card to copy its path.
