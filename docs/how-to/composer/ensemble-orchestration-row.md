# Ensemble Orchestration Row

Ensemble orchestration has transitioned to a continuous-only mode. The historical Turn/Continuous picker has been retired.
You can manage the roster and fan-out behavior directly from the Ensemble Orchestration Row in the Composer.

- **Continuous Orchestration**: Ensembles run continuously. You no longer need to explicitly select Turn mode.
- **Fan-Out**: Fan-out is a simple `Off` / `All` toggle. The previous character and turn budgeting controls have been retired.
- **Synthesis Turn**: When two or more participants speak without convergence, a bounded, single-pass synthesis turn executes before round termination to prevent stalled loops.
