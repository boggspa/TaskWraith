# Agent Pool Icons

This folder is a design-source catalogue for reusable Agent pool icons.

- `icons/*.svg` are standalone funky tech-themed SVG candidates.
- `agent-pool-icons.manifest.json` lists the icon names, slugs, files, accents, and hues.
- `agent-pool-icons.catalog.svg` is a review sheet for scanning the set quickly.

These are intentionally separate from `design-assets/agent-identicon`, which remains the subagent/nickname identicon catalogue.
