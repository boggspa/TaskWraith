# Runtime provider logos

Byte-identical runtime copies of the sourced PNGs documented in
[`design-assets/provider-logos`](../../../../../design-assets/provider-logos/).
They are used only as provider identity marks beside provider or model names.

TaskWraith's original monoline `ProviderGlyph` artwork remains the fallback for
Ensemble and unknown providers and remains selectable in generic identity icon
pickers. These provider marks do not imply affiliation, sponsorship, or
endorsement. The upstream owners' trademark and brand terms remain controlling.
