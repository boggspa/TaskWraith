# Papercuts

Small but repeatable product/runtime failures belong here when they are not
security findings. Each record must name an owner, status, user-visible scar,
and the regression or document that prevents recurrence. Security-relevant
issues belong in the maintainers' local-only `SECURITY_ENGINEERING_LEDGER.md`,
not in this public directory.

This directory is intentionally tracked. Local scratch notes remain ignored.
